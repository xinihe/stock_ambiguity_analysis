Title: Author Statement — Data Reliability and Replicability

On behalf of all authors, we provide the following statements regarding data reliability and empirical replicability for the manuscript “Global Geopolitical Risk, Ambiguity, and Emerging Market Returns: Evidence from China.”

1) Data Sources and Reliability
- GPR Index: Daily Geopolitical Risk (GPR) index by Caldara and Iacoviello, as cited in the manuscript’s Data section.
- Market Returns: CSI 300 Index and A‑share constituent returns based on official exchange data (Shanghai and Shenzhen), consistent with the manuscript.
- VIX: CBOE Volatility Index (VIX), used to capture global risk sentiment.
- Term Spread: Chinese government bond term spread (10‑year minus 1‑year yields), used as a macro control.
- Risk‑Free Rate: 3‑month SHIBOR, as specified in the manuscript.
- Ownership Classification: SOE status verified using WIND database classifications, as documented in the manuscript.

We hereby affirm that all data are valid, reliable, and obtained and processed in accordance with standard academic and professional practices described in the manuscript.

2) Empirical Work and Replicability Commitment
- All empirical data processing, construction of ambiguity measures, and statistical analyses were performed by the authors.
- The empirical results are replicable following the procedures outlined in the manuscript (including the daily ambiguity construction via cross‑entropy and the time‑series and cross‑sectional specifications).
- Upon acceptance of the paper, we will release the source code and a sample dataset sufficient to reproduce all tables and figures in a public GitHub repository, together with documentation to assist replication.

Signed,
On behalf of all authors
